# Smooth Time 0.1.0 — Fabric 1.21.1

## Кратко

- Развернуть проект из [Stonecutter Mod Template](https://github.com/rotgruengelb/stonecutter-mod-template), оставив только уже поддерживаемые шаблоном цели `1.21.1-fabric` и `1.21.1-neoforge`; активной сделать Fabric.
- Первый этап — полностью реализованный и протестированный клиентский Fabric-мод. NeoForge подключить после подтверждения поведения на Fabric, используя тот же общий код.
- Мод меняет только визуальное клиентское время: сервер, `/time query`, игровая логика и сохранение мира остаются неизменными.

## Структура проекта и метаданные

- Название: `Smooth Time`; имя артефакта/репозитория: `smooth-time`; внутренний mod id: `smooth_time`, поскольку NeoForge не допускает дефис в mod id ([NeoForge identifiers](https://docs.neoforged.net/docs/1.21.11/misc/identifier/)).
- Java-пакет: `dev.skuto.smoothtime`; версия: `0.1.0-alpha.1`; лицензия: MIT; окружение: client-only.
- Удалить демонстрационный код, Forge и лишние версии Minecraft из шаблона. Оставить Java 21 как целевой байткод; установленный JDK 25 использовать для Gradle.
- Не добавлять Fabric API, Mod Menu, Cloth Config, сетевые пакеты или команды: для первой версии достаточно Fabric Loader и Mixin.
- Публичного API не будет. Внутренние типы: контроллер визуального времени, чистые математические функции и три клиентских mixin-точки.

## Реализация сглаживания

- В начале каждого кадра через `GameRenderer#render` вычислять одно значение визуального времени и кэшировать его до конца кадра, чтобы все части атмосферы получили идентичный результат.
- Источник цели: клиентский `dayTime` плюс render partial tick. Partial tick добавлять только когда daylight cycle действительно идёт и tick manager не заморожен. Это устраняет ступени без постоянного отставания от настоящего времени.
- Через клиентский mixin к `LevelTimeAccess#getTimeOfDay(float)` возвращать угол, рассчитанный из дробного `double`-времени по ванильной формуле. Метод является общей точкой для небесного угла, а `WorldRenderer#renderSky` уже принимает кадровый `tickDelta` ([1.21.1 mappings](https://mappings.dev/1.21.1/net/minecraft/world/level/LevelTimeAccess.html), [Yarn WorldRenderer](https://maven.fabricmc.net/docs/yarn-1.21.1%2Bbuild.3/net/minecraft/client/render/WorldRenderer.html)).
- Подмена действует только во время клиентского рендера и только для текущего `ClientLevel`. Фиксированное время измерения, серверные миры и вызовы клиентской игровой логики получают ванильное значение.
- Отслеживать `ClientLevel#setDayTime(long)`: изменение на `0` или `+1` считать обычным тиком, более крупную коррекцию — скачком `/time set`, `/time add`, сна либо серверной синхронизации.
- При скачке сохранять текущую визуальную позицию и создавать циклическое смещение относительно новой цели. Выбирать кратчайшую дугу в диапазоне `[-12000, 12000)` тиков.
- Уменьшать смещение FPS-независимо: `offset *= exp(-deltaSeconds / 0.20)`. Остаточная ошибка станет меньше 1% примерно за 0,92 секунды, что соответствует выбранному адаптивному переходу около секунды.
- Использовать монотонные часы и реальный интервал между кадрами. При первом кадре, смене мира/измерения, выходе в меню или переподключении сбрасывать состояние и сразу принимать настоящее время.
- Сглаженное значение распространяется на солнце, луну, звёзды, яркость и цвета атмосферы, использующие ванильный небесный угол. Дискретная текстура фазы луны остаётся синхронизированной с сервером.
- После приёмки Fabric подключить эту же mixin-конфигурацию к `1.21.1-neoforge`, добавить корректные client-only метаданные и отдельно проверить NeoForge-сборку.

## Проверка и критерии приёмки

- Добавить JUnit-тесты для циклической арифметики: переход `23999 ↔ 0`, кратчайший путь, скачки вперёд/назад, экспоненциальное затухание и одинаковый результат при 30/60/144 FPS.
- Собрать `:1.21.1-fabric:build`, запустить `:1.21.1-fabric:runClient` и проверить чистый профиль Minecraft 1.21.1.
- В игре проверить `/tick rate 1`, `20`, `100` и `1000` при разблокированном FPS: при непрерывном времени положение неба должно изменяться каждый кадр без тик-плато.
- Проверить `/time set day|noon|night|midnight`, произвольные `/time set <value>` и `/time add`: движение начинается без скачка, идёт кратчайшим путём и практически завершается примерно за секунду.
- Проверить `doDaylightCycle false`, `/tick freeze`, паузу, Alt-Tab, вход/выход из мира, смерть, сон и переходы Overworld/Nether/End: замороженное время не дрожит, состояние между мирами не переносится.
- Проверить одиночную игру и подключение к обычному серверу без мода. Значения `/time query` и серверная механика должны совпадать с ванильными.
- После базовой приёмки провести совместимый прогон с Sodium и Iris. Шейдеры, самостоятельно вычисляющие время и игнорирующие ванильный `LevelTimeAccess`, документировать как ограничение, а не заменять собственным рендерером.
- Затем собрать и вручную повторить основной сценарий для `:1.21.1-neoforge:build`/клиента.
